# OpenAvenueSecurityAgent

Assignment 1 for my AI Security Agents coursework: make a first Gemini API call
with Python and `google-genai`, then compare responses to three defensive
cybersecurity inputs.

The experiment will record expectations before each request, preserve the actual
responses, and check at least one claim independently. This assignment is a
single-request experiment; agent functionality comes in later coursework.

Setup, code, and results will be proposed on an assignment branch through a
pull request into `main`. The PR will remain unmerged until instructor review.
